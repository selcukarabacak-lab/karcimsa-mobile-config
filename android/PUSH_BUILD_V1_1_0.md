# KARÇİMSA Android v1.1.0

Bu build Firebase Cloud Messaging push bildirim altyapısını içerir.

- CEM I araç girişi bildirimleri
- Satış aracı girişi bildirimleri
- Uygulama kapalıyken FCM bildirim desteği
- Android 13+ bildirim izni
- KARÇİMSA operasyon topic aboneliği: `karcimsa_ops`
- Özel kısa endüstriyel araç bildirim sesi
- Bildirime dokununca KARÇİMSA uygulamasını açma

Otomatik gönderici (PC/watcher) bir sonraki aşamada Firebase servis hesabı ile bağlanacaktır.
